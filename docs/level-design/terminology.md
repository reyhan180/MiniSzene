\# Level Design Terminologie (Roblox Studio)



Definitionen der Begriffe für Level Design





1\. Blockout

Eine Map wird zuerst ganz einfach mit grauen Bausteinen erstellt, ohne Farben, Texturen oder Details.

Ziel: Erst testen, ob die Wege, Abstände und das Spielgefühl passen, bevor man die Map schön gestaltet.





2\. Sightline (Sichtlinie)

Damit sind freie Bereiche auf der Map gemeint, in denen Spieler sehr weit sehen und schießen können.

Ziel: Zu lange freie Sicht verhindern, damit Scharfschützen keinen zu großen Vorteil haben.





3\. Cover (Deckung)

Möglichkeiten auf der Map (z. B. Kisten, Mauern oder Barrieren), hinter denen sich Spieler vor gegnerischen Schüssen verstecken können.

\-Full Cover: Schützt den ganzen Körper.

\-Half Cover: Schützt nur, wenn man sich duckt. Im Stehen kann man darüber schießen.



4\. Player Pathing (Spielerführung)

Damit ist gemeint, dass die Map den Spielern zeigt, wohin sie gehen sollen.

Ziel: Durch Licht, Hindernisse und Wege die Spieler automatisch zu den wichtigen Bereichen führen, ohne dass sie lange suchen müssen.



5\. Choke Point (Engpass)

Enge Stellen auf der Map (z. B. Tore, schmale Räume oder Brücken), durch die Spieler hindurchmüssen.

Ziel: Dort entstehen spannende Kämpfe, weil Spieler sich gegenseitig aufhalten oder bestimmte Bereiche verteidigen können.



6\. Power Position (Vorteilsposition)

Strategisch wichtige Plätze auf der Map (oft höher gelegen), von denen Spieler eine gute Übersicht über das Spielfeld haben.

Ziel: Diese Plätze müssen auch angreifbar sein, damit kein Spieler einen unfairen Vorteil hat.



7\. Counterplay (Kontermöglichkeit)

Eine Möglichkeit für Spieler, auf starke Gegner oder deren Taktiken zu reagieren.

Ziel: Durch alternative Wege oder Flankierungswege/Abwehr können Spieler den Gegner umgehen und haben eine faire Chance, zurückzuschlagen.
